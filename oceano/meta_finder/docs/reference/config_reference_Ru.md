# Справочник по конфигурации

Авторитетная спецификация для всех полей конфигурации. Определено в [`config.py`](../../src/meta_finder/config.py) (датакласс `Config`).

## `search_dirs`

Список директорий для поиска данных экспедиций.

- **Тип:** `Tuple[Path, ...]`
- **По умолчанию:** жёстко заданные пути (обычно не то, что вам нужно — укажите явно или используйте `--cruise-dir`)
- **CLI:** `--search-dirs`

## `cruise_dir`

Указывает одну директорию экспедиции для обработки, переопределяя `search_dirs`.

- **Тип:** `Optional[List[Path]]`
- **По умолчанию:** `None`
- **CLI:** `--cruise-dir`

## `create_info_files`

Создавать или обновлять файлы `info_devices@meta_finder.yaml`.

- **Тип:** `bool`
- **По умолчанию:** `False`
- **CLI:** `--create-info-files`

Когда True, программа сканирует директории экспедиций для поддиректорий устройств, обнаруживает устройства из файлов text_output, директорий _raw, или HDF5 файлов, и создаёт/обновляет `info_devices@meta_finder.yaml` со значениями "?" по умолчанию для отсутствующих метаданных.

## `from_data`

Извлекать метаданные из файлов данных.

- **Тип:** `bool`
- **По умолчанию:** `True`
- **CLI:** `--from-data` / `--no-from-data`

Когда True, извлекает метаданные (временные диапазоны, информацию об устройствах и т.д.) из файлов данных и объединяет с существующими info-файловыми метаданными. Когда False, использует только метаданные из существующих info-файлов без извлечения из файлов данных.

## `extract_hdf5_times`

Извлекать временные метаданные из HDF5 файлов в порядке приоритета.

- **Тип:** `bool`
- **По умолчанию:** `True`
- **CLI:** `--extract-hdf5-times` / `--no-extract-hdf5-times`

Когда файлы text_output недоступны, извлекает из: `*.proc_noAvg.h5`, `*.proc.h5`, и `_raw/*.h5`.

## `extract_hdf5_coef_dates`

Извлекать даты коэффициентов из HDF5 файлов.

- **Тип:** `bool`
- **По умолчанию:** `False`
- **CLI:** `--extract-hdf5-coef-dates` / `--no-extract-hdf5-coef-dates`

## `max_burst_time_detection`

Максимальное время в секундах для анализа burst-режима.

- **Тип:** `int`
- **По умолчанию:** `10800` (3 часа)
- **CLI:** `--max-burst-time-detection`

Код читает строки 1 и 20 для вычисления временного интервала, затем вычисляет, сколько строк необходимо для покрытия этого временного промежутка.

## `default_text_file_averaging`

Значение осреднения по умолчанию для текстовых файлов, которые не указывают осреднение.

- **Тип:** `float`
- **По умолчанию:** `2.0001`
- **CLI:** `--default-text-file-averaging`

Файлы без информации об осреднении в их именах обрабатываются как имеющие это значение, позволяя им сортироваться нормально. Значение 2.0001 имеет чуть более низкий приоритет, чем файлы 2с.

## `device_dir_pattern`

Шаблон regex для идентификации стандартных директорий устройств.

- **Тип:** `str`
- **По умолчанию:** скомпилирован из `ptn_device_dir_keywords` и `ptn_device_dir_sep`
- **CLI:** `--device-dir-pattern`

Соответствует ключевым словам устройств (`inclinometer`, `incl`, `tcm`, `wavegauge`, `wave_gauge`, `pres`, `@i[0-9]`) или типам устройств (`i`, `w`, `incl`, `wg`) после разделителей (`_`, `@`, `#`, цифры, `-`). Типы устройств требуют якоря запятой, точки с запятой или конца строки.

## `output_format`

Выходные форматы для генерации.

- **Тип:** `List[str]`
- **По умолчанию:** `["tsv"]`
- **CLI:** `--output-format`

## `output_dir`

Выходная директория для генерируемых файлов.

- **Тип:** `Optional[Path]`
- **По умолчанию:** `None` (использует директорию "meta" относительно текущей рабочей директории)
- **CLI:** `--output-dir`

## `overwrite_bad_devs_in_info_files`

Управляет выборочным обновлением отдельных записей устройств в info-файлах.

- **Тип:** `bool`
- **По умолчанию:** `True`
- **CLI:** `--overwrite-bad-devices-in-info-files` / `--no-overwrite-bad-devices-in-info-files`

Только устройства со всеми пустыми значениями ("?", "-", или "") обновляются новой информацией, сохраняя существующие не-заполнительные значения и порядок устройств.

## `raw_hdf5_cols`

Множество столбцов для запуска извлечения соответствующей информации из RAW HDF5/MAT файлов.

- **Тип:** `set`
- **По умолчанию:** `{"coef_date", "raw_date_range"}`
- **CLI:** `--raw-hdf5-cols`

Опции: "coef_date", "raw_date_range".

## `logging_level`

Глобальная настройка уровня логирования.

- **Тип:** `Union[str, int]`
- **По умолчанию:** `INFO` (20)
- **CLI:** `--logging-level`

Может быть указана как строка (DEBUG, INFO, WARNING, ERROR, CRITICAL) или числовое значение.

## `cache_files_number`

Конфигурация кэширования для чтения файлов для минимизации избыточного доступа к файлам.

- **Тип:** `int`
- **По умолчанию:** `2000`
- **CLI:** `--cache-files-number`

## `temp_dir`

Настройки временной директории.

- **Тип:** `Optional[Path]`
- **По умолчанию:** `None` (по умолчанию `src/meta_finder/temp`)
- **CLI:** `--temp-dir`

## Поля файлов метаданных

Следующие поля определены в [`io_info_files.py`](../../src/meta_finder/io_info_files.py) (`info_devices_field_names_extended`):

| Поле | Индекс | Описание |
|------|--------|----------|
| `point` | 0 | Название/номер станции |
| `sea_depth` | 1 | Глубина моря (м) |
| `height_above_bottom` | 2 | Высота прибора над дном (м) |
| `modification_symbol` | 3 | Символ модификации прибора |
| `lat` | 4 | Широта (градусы) |
| `lon` | 5 | Долгота (градусы) |
| `time_st` | 6 | Время начала хороших данных |
| `time_en` | 7 | Время конца хороших данных |
| `burst_dt` | 8 | Интервал активности прибора (с) |
| `bursts_t` | 9 | Период работы прибора (с) |
| `comment` | 10 | Комментарий |
| `coef_date` | 11 | Дата калибровки (из HDF5) |
| `time_raw_st` | 12 | Начало raw-данных |
| `time_raw_en` | 13 | Конец raw-данных |

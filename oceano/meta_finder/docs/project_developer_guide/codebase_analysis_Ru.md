# Анализ кодовой базы

Всесторонний анализ кодовой базы meta_finder, сопоставляющий каждый модуль с его функциональностью и соответствующим покрытием тестами.

## Исходные модули и функциональность

### 1. `config.py`

**Функциональность:** Управление конфигурацией, аргументы CLI, константы и настройки приложения
- Определяет глобальные константы и параметры конфигурации
- Обрабатывает разбор аргументов командной строки
- Управляет общеприложенными настройками и значениями по умолчанию

**Покрытие тестами:**
- `test_command_line_args.py` — Тесты разбора аргументов CLI
- `test_interactive_config.py` — Тесты функций интерактивной конфигурации

### 2. `parse_data_file_name.py`

**Функциональность:** Анализ имён файлов, извлечение идентификаторов устройств и сопоставление шаблонов
- Разбирает идентификаторы устройств из имён файлов и имён директорий
- Обрабатывает сложные паттерны устройств (диапазоны, группы, специальные символы)
- Извлекает метаданные из компонентов имён файлов
- Нормализует идентификаторы устройств между разными форматами

**Покрытие тестами:**
- `test_parse_filename_patterns.py` — Тесты логики сопоставления шаблонов
- `test_device_extraction.py` — Тесты извлечения идентификаторов устройств из различных источников
- `test_device_id_normalization_fix.py` — Тесты нормализации идентификаторов устройств
- `test_duplicate_device_id_fix.py` — Тесты обработки дублирующихся идентификаторов устройств

### 3. `parse_cruise_dir_name.py`

**Функциональность:** Анализ имён директорий экспедиций
- Извлекает информацию об экспедиции из имён директорий
- Обрабатывает различные соглашения об именовании
- Валидирует структуру директорий экспедиций
- Строит имена наборов данных из имён директорий экспедиции и устройства

**Покрытие тестами:**
- `test_extract_cruise_name.py` — Тесты извлечения названий экспедиций
- Интегрировано в `test_device_directory_logic.py`

### 4. `file_finder.py`

**Функциональность:** Обнаружение файлов, поиск директорий устройств и разрешение путей
- Обнаруживает директории устройств в структурах экспедиций
- Реализует алгоритмы поиска файлов
- Обрабатывает паттерны исключений и фильтры
- Разрешает паттерны устройств из путей файлов
- Извлекает устройства из директорий text output и архивов

**Покрытие тестами:**
- `test_device_directory_logic.py` — Тесты логики обнаружения директорий
- `test_file_finder_gpx_filtering.py` — Тесты фильтрации GPX файлов
- `test_excluded_dirs.py` — Тесты логики исключения директорий
- `test_file_finder_fix.py` — Тесты исправлений file finder

### 5. `metadata_extractor.py`

**Функциональность:** Чтение и разбор файлов метаданных
- Читает `info_devices@meta_finder.yaml`, `info_devices.yaml` и `info_devices.json`
- Извлекает метаданные устройств из YAML/JSON структур
- Обрабатывает множественные интервалы (суффиксы подчёркивания)
- Нормализует временные форматы
- Извлекает координаты из GPX файлов

**Покрытие тестами:**
- `test_read_metadata_files.py` — Тесты чтения файлов метаданных
- `test_info_devices_yaml_parsing.py` — Тесты разбора YAML
- `test_multiple_intervals_handling.py` — Тесты устройств с множественными интервалами

### 6. `data_processor.py`

**Функциональность:** Высокоуровневая оркестрация обработки данных
- Сортирует пути данных по приоритету для извлечения времени
- Определяет типы HDF5 файлов и их приоритеты
- Оркестрирует выбор источника данных

**Покрытие тестами:**
- `test_sort_data_paths.py` — Тесты сортировки путей данных
- `test_h5_type_and_priority.py` — Тесты классификации HDF5 файлов

### 7. `data_proc_funcs.py`

**Функциональность:** Конкретные функции обработки файлов
- Извлекает временные метаданные из текстовых файлов
- Извлекает временные диапазоны из комбинированных файлов
- Обрабатывает файлы с разделением по времени (несколько файлов для одного устройства)
- Анализирует паттерны burst в метках времени

**Покрытие тестами:**
- `test_extract_time_info.py` — Тесты извлечения времени из текстовых файлов
- `test_extract_time_ranges_combined.py` — Тесты извлечения времени из комбинированных файлов

### 8. `hdf5_processor.py`

**Функциональность:** Извлечение метаданных HDF5/MAT файлов
- Извлекает идентификаторы устройств из имён групп HDF5
- Извлекает временные диапазоны из таблиц HDF5
- Извлекает даты коэффициентов из групп coef HDF5
- Обрабатывает как нормализованные, так и ненормализованные имена групп

**Покрытие тестами:**
- `test_hdf5_extraction.py` — Тесты извлечения метаданных HDF5
- `test_hdf5_coef_date.py` — Тесты извлечения дат коэффициентов

### 9. `io_info_files.py`

**Функциональность:** Ввод/вывод YAML/JSON info файлов
- Читает и записывает файлы `info_devices@meta_finder.yaml`
- Обрабатывает множественные интервалы (суффиксы подчёркивания)
- Преобразует между форматами list/tuple и dict
- Сохраняет порядок устройств во время обновлений

**Покрытие тестами:**
- `test_io_info_files.py` — Тесты ввода/вывода info файлов
- `test_multiple_intervals_handling.py` — Тесты обработки множественных интервалов

### 10. `file_writer.py`

**Функциональность:** Генерация выходных файлов
- Записывает `{yymmdd_HHMM}_files_TCM.tsv` — список обработанных файлов
- Записывает `{yymmdd_HHMM}_meta_TCM.tsv` — консолидированная таблица метаданных
- Обрабатывает устройства с множественными интервалами (одна строка на интервал)
- Вычисляет индикаторы качества из путей файлов данных

**Покрытие тестами:**
- `test_file_writer.py` — Тесты генерации TSV вывода
- `test_write_metadata_table.py` — Тесты записи таблицы метаданных

### 11. `collect.py`

**Функциональность:** Основная точка входа приложения и оркестрация обработки
- Оркестрирует весь pipeline сбора метаданных
- Ассоциирует устройства с файлами данных
- Извлекает временную информацию из приоритизированных источников
- Обрабатывает устройства с множественными интервалами
- Управляет слиянием метаданных на уровне полей

**Покрытие тестами:**
- `test_collect.py` — Тесты основного pipeline сбора
- `test_get_absent_meta.py` — Тесты ассоциации метаданных
- `test_process_all_metadata.py` — Тесты полной обработки метаданных

### 12. `create_info_files.py`

**Функциональность:** Создание и обновление `info_devices@meta_finder.yaml`
- Сканирует директории экспедиций для поддиректорий устройств
- Обнаруживает устройства из файлов text_output, директорий _raw, или HDF5 файлов
- Извлекает информацию о временных диапазонах из файлов данных
- Создаёт/обновляет info файлы со значениями "?" по умолчанию для отсутствующих метаданных
- Выборочно обновляет записи устройств (сохраняя порядок и не-заполнительные значения)
- Дедупликация против существующих `info_devices.yaml`

**Покрытие тестами:**
- `test_create_info_files_unit.py` — Тесты создания info файлов
- `test_create_info_files_integration.py` — Тесты полного workflow

### 13. `utils_sys.py`

**Функциональность:** Системные утилиты для обработки архивов
- Читает первые и последние строки файлов внутри ZIP или 7z архивов
- Рекурсивно перечисляет все файлы/папки в архивах
- Обрабатывает разрешение путей в архивах

**Покрытие тестами:**
- `test_utils_sys.py` — Тесты утилит архивов

### 14. `parse_data_file_name.py`

**Функциональность:** Анализ имён файлов и извлечение идентификаторов устройств
- Разбирает идентификаторы устройств из имён файлов, используя regex
- Расширяет диапазоны устройств (например, `27-30` → `27,28,29,30`)
- Обрабатывает группы с точкой с запятой
- Обрабатывает скобки и сложные паттерны
- Нормализует идентификаторы устройств

**Покрытие тестами:**
- `test_parse_filename_patterns.py` — Тесты сопоставления шаблонов
- `test_device_id_normalization_fix.py` — Тесты нормализации
- `test_duplicate_device_id_fix.py` — Тесты обработки дубликатов

### 15. `parse_cruise_dir_name.py`

**Функциональность:** Анализ имён директорий экспедиций и построение имён наборов данных
- Извлекает названия экспедиций из имён директорий
- Строит уникальные имена наборов данных с датными префиксами
- Обрабатывает дублирующиеся названия экспедиций с разными датами
- Извлекает даты из поддиректорий устройств

**Покрытие тестами:**
- `test_extract_cruise_name.py` — Тесты извлечения названий экспедиций
- `test_add_dataset_name.py` — Тесты построения имён наборов данных

### 16. `similarity.py`

**Функциональность:** Вендорное иерархическое сходство имён папок (без внешних зависимостей)
- Чистый Python-порт name-similarity из `match_dirs`, используемый `post_processing`
- `hierarchical_weighed_similarity()` + `HIGH/LOW_CONFIDENCE_THRESHOLD`

### 17. `post_processing/`

**Функциональность:** Формально интегрированные пост-утилиты (входят в wheel)
- `path_checker.py` — проверка доступности путей TSV + mapping переименованных папок
- `path_checker_main.py` — CLI `check-paths` (`python -m meta_finder.post_processing.path_checker_main`)
- `check_device_dirs.py` — отчёт о доступности device-директорий + иерархия symlink (`check-device-dirs`)

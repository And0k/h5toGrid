# Функциональность HDF5

Анализ и документация обработки HDF5/MAT файлов в meta_finder.

## Обзор

Функциональность HDF5 извлекает информацию о временных диапазонах из HDF5 файлов как альтернативный источник данных для обработки метаданных. MAT файлы (`.mat`) в директориях `_raw` обрабатываются так же, как HDF5 файлы с сырым приоритетом.

## Поддерживаемые типы файлов

| Тип | Приоритет | Описание |
|-----|-----------|----------|
| `proc_noAvg` | 1 | Обработанный HDF5 без осреднения |
| `proc` | 2 | Обработанный HDF5 с осреднением |
| `proc_Avg` | 2 | Обработанный HDF5 с группами по устройствам |
| `raw` | 3 | Сырые HDF5/MAT файлы в `_raw/` |

## Структура файлов

### proc_noAvg.h5

```
/
├── i63/  # device_id_proc (нормализованное имя устройства)
│   ├── table (столбцы: ['index', 'v', 'u', 'inclination', 'Battery', 'Temp'])
│   └── logFiles/
│       └── table (столбцы: ['index', 'fileName', 'fileChangeTime', 'DateEnd', 'DateProc'])
```

### raw.h5

```
/
├── incl63/  # device_id_raw (ненормализованное имя устройства)
│   ├── table (столбцы: ['index', 'Ax', 'Ay', 'Az', 'Mx', 'My', 'Mz', 'Battery', 'Temp'])
│   ├── coef/
│   └── logFiles/
│       └── table (столбцы: ['index', 'fileName', 'fileChangeTime', 'DateEnd', 'DateProc'])
```

### proc.h5

```
/
├── bin600s/  # averaging bin
│   └── table (столбцы: ['index', 'Vabs_i03', 'v_i04', ...])
```

### proc_Avg.h5

```
/
├── i04bin2s/  # device_id с averaging bin
│   └── table (столбцы: ['index', 'Vabs', 'v', 'u', 'Inclination', 'Temp'])
├── i05bin2s/
│   └── table (столбцы: ['index', 'Vabs', 'v', 'u', 'Inclination', 'Temp'])
└── i03bin600s/
    └── table (столбцы: ['index', 'Vabs', 'v', 'u', 'Inclination', 'Temp'])
```

## Извлечение устройств

Идентификаторы устройств извлекаются из имён групп HDF5, используя паттерн:

```
\d*[@#_-]?(?P<type>[iwp])(?:ncl|nkl)?_?(?P<model>[bp]?)0*(?P<number>\d+)
```

Поддерживаются как нормализованные (`i63`), так и ненормализованные (`incl63`) имена групп.

## Извлечение временных диапазонов

Временные диапазоны извлекаются из столбца `index` таблиц HDF5. Логика извлечения:

1. Открывает HDF5 файл и находит группу устройства
2. Читает dataset `table`
3. Идентифицирует столбец времени (обычно `index`)
4. Извлекает первую и последнюю валидные временные метки

## Извлечение коэффициентов

Даты коэффициентов извлекаются из группы `coef`, когда `extract_hdf5_coef_dates=True` или `coef_date` в `raw_hdf5_cols`.

## Условия пропуска

Извлечение HDF5 пропускается, когда временные метаданные уже доступны в info файлах. Если `time_st`, `time_en`, или `coef_date` уже содержат значимые значения (не заполнители типа "?", "-", или пустые строки), существующие метаданные сохраняются.

## Реализация

- `hdf5_processor.py` — Функции извлечения HDF5/MAT
- `data_processor.py` — `get_h5_type_and_priority()` классифицирует файлы
- `collect.py` — оркестрирует извлечение через `extract_time_metadata_from_prioritized_sources()`

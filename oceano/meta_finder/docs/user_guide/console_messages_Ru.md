# Сообщения консоли

Файлы лога (`meta/{yymmdd_HHMM}_{meta_finder или mf_{сокращённая конфиг}}.log`) содержат WARNING и ERROR сообщения.

## Уровни логирования

| Уровень | Используется для |
|---------|------------------|
| `WARNING` | Аномалии, требующие внимания пользователя: новые устройства найдены, отсутствующие метаданные, сбои извлечения |
| `INFO` | Этапы pipeline: сводка обнаружения, обработанные файлы, записанные метаданные |
| `DEBUG` | Диагностические детали: извлечение на устройство, сопоставление файлов, приоритетная сортировка |

## Ключевые сообщения

### Требование двух запусков

Когда новые устройства обнаружены во время первого запуска, программа выводит:

```
WARNING: NEW DEVICES FOUND - REQUIRES SECOND RUN
```

Это указывает, что файлы `info_devices@meta_finder.yaml` были созданы с значениями-заполнителями и необходим второй запуск для извлечения фактических временных метаданных.

### Устаревшие конфигурации

Когда существующие файлы метаданных ссылаются на файлы данных, которые больше не существуют:

```
WARNING: Stale configs detected for devices: i01, i03
```

### Извлечение HDF5

Когда извлечение HDF5 пропущено, потому что метаданные уже существуют:

```
DEBUG: Skipping HDF5 extraction for i01 — time metadata already present
```

## Тестовое логирование

Для централизованного логирования в тестах используйте:

```python
from utils.logging_config import setup_logging
logger = setup_logging(__name__, console_level=logging.DEBUG, file_level=logging.DEBUG)
```

Все тестовые логи записываются в `test_data/meta_temp/logs/` во время тестовой сессии.

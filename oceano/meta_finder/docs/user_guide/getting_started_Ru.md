# Руководство по началу работы

## Что такое meta_finder

**meta_finder** собирает метаданные из файлов в директориях экспедиций для инклинометров (TCM), волнографов и комбинированных устройств АО ИО РАН. Программа сканирует директории данных, обнаруживает устройства, извлекает временные диапазоны и другую метаданные, и создаёт сводные TSV-таблицы.

## Быстрый старт

```bash
# 1. Первый запуск: обнаружить устройства и создать info_devices@meta_finder.yaml
pixi run collect --create-info-files --no-from-data

# 2. Проверить и отредактировать созданные YAML-файлы в каждой директории устройств
#    Добавить отсутствующие названия станций, глубины, координаты и т.д.

# 3. Второй запуск: извлечь временные метаданные из файлов данных
pixi run collect --create-info-files
```

При первом запуске программа создаёт `info_devices@meta_finder.yaml` файлы в каждой директории устройств с заполнителями. После ручного просмотра и редактирования, перезапустите для извлечения фактических временных данных.

## Обзор workflow

```
┌─────────────────────────────────────────────────────────────┐
│  1. Обнаружение директорий экспедиций                        │
│     Сканирование настроенных директорий для YYMMDD_{cruise_name}/   │
├─────────────────────────────────────────────────────────────┤
│  2. Обнаружение директорий устройств                         │
│     Поиск поддиректорий inclinometer/ wavegauge             │
├─────────────────────────────────────────────────────────────┤
│  3. Обнаружение файлов метаданных                            │
│     Чтение info_devices@meta_finder.yaml / .yaml / .json   │
├─────────────────────────────────────────────────────────────┤
│  4. Обнаружение файлов данных                               │
│     Поиск text_output, _raw, HDF5 файлы для каждого устройства │
├─────────────────────────────────────────────────────────────┤
│  5. Извлечение времени                                      │
│     Извлечение временных диапазонов из приоритизированных источников │
├─────────────────────────────────────────────────────────────┤
│  6. Генерация вывода                                        │
│     Запись meta_TCM.tsv + files_TCM.tsv                     │
└─────────────────────────────────────────────────────────────┘
```

## Что вы получаете

```text
cruise_dir/
├── inclinometers/ or wavegauges/
│   ├── info_devices@meta_finder.yaml  ← сгенерированные/обновлённые метаданные
│   ├── info_devices.yaml              ← пользовательские метаданные (сохраняются)
│   ├── text_output/
│   │   └── *.tsv, *.txt, *.csv
│   ├── _raw/
│   │   └── *.h5, *.mat, *.txt
│   └── *.proc_noAvg.h5, *.proc.h5
└── navigation/ or map/
    └── *.gpx

meta/                                    ← выходная директория
├── {yymmdd_HHMM}_files_TCM.tsv          ← список обработанных файлов
└── {yymmdd_HHMM}_meta_TCM.tsv          ← сводная таблица метаданных
```

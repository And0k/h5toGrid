# Вычисление давления по полиному `P_t`

Как зонды типа `p` преобразуют сырые отсчёты давления в физическое давление —
термокомпенсированный двумерный полином
[`input.coefs.P_t`](../reference/config_reference_Ru.md#inputcoefs--калибровочные-коэффициенты).

Полином вычисляется как `numpy.polynomial.polynomial.polyval2d(u, t, P_t)`:

$$P(u, t) = c_{00} + c_{10}\,u + c_{01}\,t + c_{20}\,u^2 + c_{11}\,u\,t + c_{02}\,t^2$$

где

- $u$ — сырые отсчёты давления (канал `P` / `P_counts`);
- $t$ — температура (канал `Temp`);
- элемент `P_t[i][j]` — коэффициент при $u^{i}\, t^{j}$; используются только
  шесть коэффициентов суммарной степени $\le 2$, остальные ячейки матрицы
  3×3 — нули.

Расчётное давление — как откалибровано: относительно стандартного
атмосферного давления $P_{0} = 10.1325$ дБар.

## Происхождение коэффициентов

Коэффициенты берутся из строк заводской калибровки
(`A + B * u - C * t - D * u**2 + E * u * t + F * t**2`), датированных по
каждому калибровочному запуску. Скрипт
[coef_poly2array.py](../../scripts/coef_poly2array.py) разбирает строку,
упаковывает коэффициенты в матрицу 3×3 и записывает группу `/{tbl}/coef/P_t`
источника коэффициентов (HDF5/NC или YAML-экспорт для пофайловых коэффициентов).

Восстановить символьную формулу из сохранённой матрицы:
`sympy.expand(polyval2d(Symbol('u'), Symbol('t'), P_t))`.

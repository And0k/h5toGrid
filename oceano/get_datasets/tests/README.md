# Test Directory for `get_datasets`

This directory contains unit and integration tests for the data downloading and processing scripts within the `get_datasets` module.

## Files:

*   [`test_data/create_dummy_netcdf_files.py`](test/test_data/create_dummy_netcdf_files.py):
    *   **Purpose**: This script is used to generate dummy NetCDF files (`dummy_input.nc` and `dummy_angular_input.nc`) in the `test_data` subdirectory. These files with 2x2 latitude/longitude grids (latitude: 54.94-55.06, longitude: 20.19-20.31) and two time steps (2023-08-20 00:00 and 2023-08-20 01:00) are designed to mimic the structure of real CMEMS data and are used by the unit tests to avoid complex mocking of `xarray` objects and external data dependencies.
    *   **Usage**: Run this script directly using `python create_dummy_netcdf_files.py` to generate the test data.
    *   **Expected Output**: Two NetCDF files (`dummy_input.nc` and `dummy_angular_input.nc`) will be created in the `test_data` directory.

*   [`test_download_copernicus_point.py`](test/test_download_copernicus_point.py):
    *   **Purpose**: This file contains integration tests for the `download_copernicus_point.py` script. It tests the end-to-end workflow of downloading wind data from Copernicus Marine Service for a specific point.
    *   **Key Test Functions**:
        *   `test_download_copernicus_point_integration()`: Verifies the successful download and processing of wind data.

*   [`test_download_copernicus_region.py`](test/test_download_copernicus_region.py):
    *   **Purpose**: This file is intended to contain integration tests for downloading data from Copernicus Marine Service for a specified region. (Note: Implementation may be pending or in progress).
    *   **Key Test Functions**: (To be defined upon implementation)

*   [`test_unit_download_copernicus_point.py`](test/test_unit_download_copernicus_point.py):
    *   **Purpose**: This file contains unit tests for individual functions within `d_utils.py` and `manager.py`, specifically focusing on the `interp_to_point` and `DownloadHistoryManager` functionalities. This file uses extensive mocking to isolate units of code.

*   [`test_unit_download_copernicus_point_simplified.py`](test/test_unit_download_copernicus_point_simplified.py):
    *   **Purpose**: This is a simplified version of `test_unit_download_copernicus_point.py`, created to reduce the complexity of mocking and improve test maintainability. It leverages the dummy NetCDF files generated by `create_dummy_netcdf_files.py` to test `interp_to_point` with more realistic data inputs.
    *   **Key Test Functions**:
        *   `test_download_history_manager_init()`: Tests the initialization of `DownloadHistoryManager`.
        *   `test_download_history_manager_log_download()`: Tests logging a download entry.
        *   `test_download_history_manager_load_history()`: Tests loading history from a file.
        *   `test_interp_to_point()`: Tests the `interp_to_point` function with non-angular variables using dummy data.
        *   `test_interp_to_point_angular_vars()`: Tests the `interp_to_point` function with angular variables using dummy data.

## Running Tests:

To run all unit tests in this directory, navigate to the `h5toGrid` root directory and execute:

```bash
python.exe -m pytest test/test_unit_download_copernicus_point_simplified.py -v -s
```

(Note: Integration tests in `test_download_copernicus_point.py` and `test_download_copernicus_region.py` may require Copernicus Marine Service credentials and internet access to run successfully.)
